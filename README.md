# yari's system24

a tui-style discord theme, based on refact0r's system24.
it's a lot faster. glhf. uncomment auto hide if u want idgaf

## install
1. add `https://raw.githubusercontent.com/yari-dog/system24/main/theme/system24.theme.css` to your theme import links.

[spotify](/theme/flavors/spotify-text.theme.css)
[catpuccin](/theme/flavors/catppuccin-mocha.theme.css)
[gruvbox](/theme/flavors/gruvbox-material.theme.css)
[monochrome](/theme/flavors/monochrome.theme.css)
